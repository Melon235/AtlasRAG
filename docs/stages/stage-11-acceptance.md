## 2. Verification Strategy Across Layers A–D

### Layer A — Offline Unit and Contract Tests (`tests/stage11/`)

- Executed under `make verify` and `make test-stage11` with zero Docker, network, GPU, or paid API dependencies.
- Uses existing fake providers and `ApplicationComposition.start(build_business=...)` / fake `ApplicationCoordinator`.
- Covers: `ServerConfig`, `QueryRequest`/`QueryResponse` validation & `max_response_bytes` enforcement, `SessionRegistry` capacity/TTL/in-flight deletion, `MaintenanceOperationRegistry` reservation/handoff/`SyncOutcome`+`ServingSafety` projection, `InvocationEventBus` projection/slow-consumer overflow, `auth.py` Host/Origin/CSRF/token/body-limit checks, `errors.py` mapping for all 15 `ErrorCode`s, CLI `argparse` & `httpx.MockTransport` (redirect/proxy refusal, loopback URL check, `O_NOFOLLOW` file checks), and `QuerySupervisor` disconnect/settlement.

### Layer B — Real Local Transport Tests (`tests/stage11/test_real_server_transport.py`)

- Launches real `atlasrag serve` subprocesses bound to ephemeral loopback ports, using an isolated temporary `HOME` state directory and fake business bundle.
- **Explicitly supplements ASGI `TestClient`** to prove over real TCP sockets:
  - Abrupt TCP disconnect mid-JSON `POST /api/v1/query` AND mid-SSE `POST /api/v1/query/stream` -> `InFlightTaskRegistry` + `QueryLease` + session refcount settlement (`S11-15`, `S11-24`).
  - Competing `atlasrag serve` fails exit `3` with primary server's `control.token`, `server.json`, and `runtime.lock` untouched (`S11-01`).
  - Socket-bind failure (`EADDRINUSE`) fails exit `4` leaving zero `server.json` and releasing `runtime.lock` (`S11-04`).
  - SSE pre-admission `503` JSON vs post-admission `200` `accepted` frame #1, concurrent invocation isolation, cache-hit non-fabrication, failure after admission before first observation (`S11-13`, `S11-14`).
  - Slow-reader buffer eviction + `sse_send_timeout_seconds` stalled-stream cleanup (`S11-16`).
  - Bounded `SIGTERM`/`SIGINT` drain with idle/slow clients (`S11-22`), hung-worker exit `4` + lock retention, and `pidfd`-verified `atlasrag stop --force` (`S11-23`).

### Layer C — Real Infrastructure Integration (`tests/integration/test_stage11_*.py`, `scripts/stage11_verify.sh`)

- Reuses the fail-closed `scripts/stage10_isolation.py` container/volume/port/DB/Redis/Milvus ownership discipline against ephemeral `postgres:17.8-alpine`, `redis:8.2.10-alpine`, and `milvusdb/milvus:v2.6.20`.
- Runs a real `atlasrag serve` process wired to the isolated endpoints with fake embedding/LLM providers.
- Verifies HTTP/SSE end-to-end queries, same-session Redis `HIT`, cross-session isolation, `POST /control/sync` invalidation, Redis outage bypass & recovery, `BLOCKED` recovery via `POST /control/recover`, and clean shutdown teardown (`remaining=0`).

### Layer D — Independent Review Gate

1. **Architecture & Boundary Compliance:** `ApplicationComposition=1`, `ApplicationCoordinator=1`, `ApplicationServerService` FastAPI-independence, zero MCP premature code, zero RAG semantic changes, `check_import_boundaries.py` pass.
2. **Ownership, Lifecycle & Concurrency Correctness:** Pre-lock state immutability, socket-bind ordering, `DisconnectMonitor` + `QuerySupervisor` settlement on JSON & SSE, `on_admitted` SSE ordering, bounded Uvicorn drain, `pidfd` + `starttime` verification, `MaintenanceOperationRegistry` vs `InFlightTaskRegistry` separation.
3. **Security Audit:** Host/Origin/CSRF/body-size middleware, `0o600` `control.token`, CLI loopback URL / `follow_redirects=False` / `trust_env=False` / `O_NOFOLLOW` enforcement.
4. **Cache Correctness Audit:** Lookup-only `QueryCacheStatus` truth, `CacheFreshnessBarrier`, Lua fence preservation, session ID safety.
5. **Real-Infra Isolation & Evidence Audit:** Zero impact on `deploy/local/.env` / dev volumes, `make verify`, Layer B & C outputs, and `12/12` Stage 9 artifact integrity.
